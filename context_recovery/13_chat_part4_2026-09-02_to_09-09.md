Plain-English glossary used below:
- **0DTE** = option that expires the same day.
- **Lab / live lab** = the paper-trading "forward test" the project runs every market day (no real orders). Two "arms": the OPTIONS arm (buys ATM / ATM+-1 contracts on QQQ and SPY) and the SHARES arm (same signals traded as plain shares, $10,000 per trade).
- **Freeze / config hash** = the lab's rules were frozen on 2026-08-28; a short hash fingerprints the definitions so nobody can quietly change them. Changing the symbol list changes the hash.
- **bp (basis point)** = 1/100 of a percent. 3.34 bp on a $700 share is roughly 23 cents.
- **Holm** = a correction that makes it harder to "win" when many things are tested at once. **Pre-registration** = writing the pass/fail rule down before running the test.
- **CI** = confidence interval, the range the true number probably sits in.
- **IMB** = IntradayMomentumBoundary, the one setup that works on shares in the 10-year history. **MOMO_CHASE** = the setup that encodes the owner's own momentum-chasing habit.
- **ThetaData / Theta Terminal** = the paid market-data vendor and the local program (a Java process on 127.0.0.1:25503) that serves it.
- **VRP** = variance risk premium (options usually cost more than the movement that follows). **HAR** = a standard volatility-forecast benchmark. **QLIKE** = the error score used for volatility forecasts (lower is better).
- **HF / Space** = HuggingFace, and the public demo app "ProfitBook" hosted there for recruiters.
