**Small glossary** (terms used below):
- **RV** = realised variance, how much price actually moved. **IV** = implied variance, what option prices say will happen.
- **HAR-RV** = a simple linear forecaster of future RV from yesterday's, last week's and last month's RV. **HAR-IV** = the same plus IV as an input.
- **QLIKE** = the loss score for variance forecasts; lower is better, and it punishes under-forecasting more than over-forecasting.
- **DM test** (Diebold-Mariano) = tests whether one forecaster really beats another; "clustered by session" means each trading day counts as one data point, not each minute.
- **Lookahead** = a calculation that accidentally uses future information. An **audit** here means deliberately injecting future information and checking the score gets better (if it does not, the pipeline already saw the future).
- **Spread** = difference between the price you can sell at (bid) and buy at (ask). **Mid** = halfway between.
- **Held-out block** = the 2024 data, reserved to be looked at once.
- **Pre-registration** = writing the pass/fail rules before running the test.
- **bp** = basis point, one hundredth of a percent.

- **Do not buy the options plan back (09-09 03:48).** The 769-session archive already holds everything the experiment needs; nothing in the current work needs new option data.
- **Drop Muon (09-09 03:40, confirmed by research 09-10 22:47).** A 20k-parameter MLP gains nothing; the benchmark evidence is +0.32% for 3.03 times tuning time; the silent AdamW substitution came from the assistant's own fallback, so the rule is delete the fallback.

- **Rebuild the whole frame for the Feb-2020 fallback and again for halt bars.** Because rolling features carried the damage forward. Abandoned: patching ten files.
